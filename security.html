Auditable by design

Site Security & Privacy

THOR-SEC is intentionally built as a minimal static site. The security model favors fewer moving parts, public source, and checks that can fail closed before deployment.

Runtime Surface

  • No client-side JavaScript.
  • No HTML forms.
  • No cookies or analytics.
  • No third-party fonts or runtime assets.
  • Same-origin CSS and images.

Browser Policy

  • Restrictive meta Content Security Policy.
  • Scripts, forms, frames, workers, objects, and network connections are denied.
  • Remote runtime images and styles are denied.
  • Referrer policy is no-referrer.

Deployment Gates

  • GitHub Actions runs a static security audit on every push and pull request.
  • The audit checks local links, duplicate IDs, forbidden active-content tags, inline handlers/styles, insecure URLs, XML validity, and security metadata.
  • The workflow uses read-only repository permissions and a commit-pinned checkout action.
