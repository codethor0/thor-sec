  1. 2026-10-02 · paper · DOI 10.5281/zenodo.23109676

    Memory-Egress Cryptographic Interlock (MECI)

    MECI treats AI memory protection as a machine-enforced capability-separation problem: unreleased protected information must not be reachable from any enabled gated egress channel. The release includes formal safety and epoch arguments, TLA+ models, negative controls, and an independent reference checker.

  2. 2026-09-27 · paper · DOI 10.5281/zenodo.23001045

    Mission-Invariant Architecture Morphing (MIAM)

    Most moving target defenses change addresses, ports, or hosts. MIAM reshapes an application's internal service graph across security epochs while its external interface stays fixed, so the dependency map an attacker builds after initial access goes stale. Includes a retention model showing that a finite variant pool leaves a nonzero knowledge floor.
